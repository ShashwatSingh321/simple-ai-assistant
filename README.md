

\# Simple AI Assistant



A beginner-friendly Python project to build a local AI assistant using Ollama and the Qwen3:4b language model.



\## Project Goal



The goal is to send a prompt from a Python program to a locally running language model and display its response.



\## Planned Technology Stack



\- Python

\- Ollama

\- Qwen3:4b

\- OpenAI-compatible Python client
